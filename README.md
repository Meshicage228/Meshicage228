## Hi, I'm Vlad 👋

<img align="right" alt="Coding" width="380" src="https://i.pinimg.com/originals/b9/49/c8/b949c86a570df07a7440abe39405834c.gif">

**Java Developer** from Minsk, Belarus.

I work on a B2B SaaS platform in the hospitality domain — backend services,
data pipelines, and the dashboards on top of them. Day to day that means
Spring Boot, a lot of database work, message queues, and enough frontend
to ship a feature end to end without handing it off.

I got into programming through computer science olympiads in school, went
through BSUIR and a few intensives, and have been doing this commercially
since 2025.

- 💼 Java Developer @ **GP Solutions**
- 🎓 BSc, **BSUIR** - Software Engineering, 2026
- 🧩 Currently building a standalone API service from scratch
- 📊 Most of my work lives in private repos, so the contribution graph
     below is only part of the picture
- 💬 Happy to talk about backend architecture, data quality, or observability
